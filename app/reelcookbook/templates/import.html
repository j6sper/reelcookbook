Instagram login

{% if has_cookies %}

✓ Saved. It's used to download Instagram posts.

{% else %}

Instagram only lets logged-in accounts download posts, so {{ app_name }} needs your login cookies. TikTok doesn't need this.

{% endif %}
{{ "Replace the login" if has_cookies else "How to add it" }}
  1. On a computer, log in to instagram.com in Chrome or Firefox.
  2. Install the browser extension “Get cookies.txt LOCALLY”.
  3. On instagram.com, open the extension and choose Export (Netscape format). You get a file like www.instagram.com_cookies.txt.
  4. Upload it here. It's stored privately on your server. It works like a password, so don't share it. Logging out of Instagram in that browser cancels it.

Add all your saved posts

Get the file from Instagram
  1. Instagram app → profile → ☰ → Accounts Centre → Your information and permissions → Download your information.
  2. Choose Some of your information, tick Saved, choose Download to device, format JSON, date range All time.
  3. Instagram emails you when it's ready (it can take a while). Download the .zip.
Get the file from TikTok
  1. TikTok app → Profile → ☰ → Settings and privacy → Account → Download your data.
  2. Choose JSON, then Request data. When it's ready, download it from the same screen.

Not every saved post is a recipe{% if writer_on %}; Claude skips the ones that aren't{% endif %}. Instagram posts are downloaded a couple of minutes apart so the account isn't flagged, so a big list takes a while.
