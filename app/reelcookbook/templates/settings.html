How to reach Claude
How to get a subscription token

You need a paid Claude plan (Pro or Max) at claude.ai. The token lasts a year, and only lets {{ app_name }} ask Claude questions: it can't see your chats or change your account.

  1. On the computer running {{ app_name }}, open a terminal in the reelcookbook folder and run:
    docker compose exec reelcookbook claude setup-token
  2. It shows a link. Open it in any browser (your phone is fine), sign in to Claude and tap Authorize.
  3. Claude shows a code. Copy it, paste it back into the terminal and press Enter.
  4. The terminal prints your token, starting sk-ant-oat01-. Copy all of it and paste it above.

Already have Claude Code on another computer? claude setup-token works there too. Each person should use their own Claude account: don't share a token between households.

How to get an API key
  1. Go to the Claude Console (platform.claude.com) and sign up or log in. This is separate from a claude.ai subscription.
  2. Open Billing and add some credit ($5 goes a long way: each post costs a few cents).
  3. Open API keys → Create key, give it a name like “{{ app_name }}”, and copy it. It starts sk-ant-api03- and is only shown once.
  4. Paste it above.
